📲 Installing the PWA

Amor Medical is a Progressive Web App (PWA), which means you can install it directly to your device's home screen for a native app-like experience — no app store required!

📱 Installing on iPad / iPhone (iOS)

Open in Safari

Navigate to the Amor Medical app URL in Safari. Note: Installation only works in Safari on iOS devices.

Tap the Share Button

Tap the share icon (📤) at the bottom of the screen (or top on iPad).

Select "Add to Home Screen"

Scroll down in the share menu and tap "Add to Home Screen".

Name and Add

Keep the name "Amor Medical" or customize it, then tap "Add" in the top right corner.

Once installed, the app will open in full-screen mode without Safari's navigation bars, just like a native app!

🤖 Installing on Android

Open in Chrome

Navigate to the Amor Medical app URL in Chrome browser.

Look for Install Prompt

You may see an "Install App" banner at the bottom, or tap the menu (⋮) and select "Install app" or "Add to Home screen".

Confirm Installation

Tap "Install" on the confirmation dialog. The app icon will appear on your home screen.

💻 Installing on Desktop (Chrome/Edge)

If you see the 📲 Install App button in the app's top navigation bar, simply click it to install. Alternatively:

  • In Chrome: Click the install icon in the address bar, or Menu → "Install Amor Medical"
  • In Edge: Click the install icon in the address bar, or Menu → Apps → "Install this site as an app"

⚙️ First-Time Setup

When you first open Amor Medical, here's what to do:

Configure Your Practice

Navigate to Settings → Practice and enter your practice name, address, NPI, and contact information.

Add Providers

Go to Providers tab and add all providers who will be using the system. Include credentials (MD, DO, NP, PA) and specialties.

Set Up Note Templates

Review and customize SOAP note templates in Settings → Templates to match your workflow.

Configure Scheduling

Set up appointment types, durations, and room assignments in Scheduling → Settings.

🔄 Refreshing & Updating the App

Amor Medical automatically checks for updates, but you can also manually refresh to ensure you have the latest version.

The Refresh Button 🔄

Located in the top navigation bar, the green 🔄 Refresh button performs a "hard refresh" that:

  • Clears cached app files
  • Unregisters the service worker
  • Downloads the latest version from the server
  • Reloads the entire application

Use the Refresh button whenever you notice something isn't working correctly, or when you see the "Update Available" banner.

Update Banner 🎉

When a new version is available, you'll see a colorful banner at the top of the screen:

🎉 Update available! — Tap to refresh

Simply tap the banner to update immediately.

Settings → Check for Updates

For more detailed version info, open ⚙️ Settings from the top bar:

  • App Version — Your currently installed version
  • Server Version — The latest available version
  • Last Updated — When you last refreshed

Full Reset (Nuclear Option) 🗑️

If you're experiencing persistent issues, use the 🗑️ Full Reset button in Settings. This clears:

  • All cached data
  • Service worker registration
  • Local storage
  • Session storage

Full Reset will clear any locally-stored preferences. Use only as a last resort for troubleshooting.

👤 Patients

The Patients module is the heart of the EMR. Here you manage patient demographics, insurance, encounters, and clinical documentation.

Navigating the Patient List

Click 🧑‍🤝‍🧑 Patients in the sidebar to view all patients. The list shows:

  • Name — Patient's full name
  • DOB — Date of birth
  • MRN — Medical Record Number
  • Phone — Primary contact number
  • Status — Active, Inactive, or Deceased

➕ Adding New Patients

To create a new patient record:

Click "➕ New Patient"

Located at the top of the Patients list or in the right panel quick actions.

Enter Demographics

Fill in required fields: First Name, Last Name, Date of Birth, and Sex. Additional fields include SSN, address, phone, and email.

Add Insurance (Optional)

Click "Add Insurance" to enter primary and secondary insurance information.

Save Patient

Click "Save Patient" to create the record. The patient will be assigned an MRN automatically.

Use the 📷 Camera feature to quickly capture insurance cards and driver's licenses to auto-populate fields.

🔍 Searching & Filtering Patients

Quickly find patients using the search bar at the top of the screen:

  • By Name — Type first or last name
  • By MRN — Enter the full or partial MRN
  • By DOB — Enter date in MM/DD/YYYY format
  • By Phone — Enter the phone number

Advanced Filters

Click the 🔽 Filter button to access advanced filters:

  • Status (Active/Inactive)
  • Insurance type
  • Primary provider
  • Last visit date range

📝 Clinical Notes (SOAP)

Amor Medical uses the SOAP format for clinical documentation — a structured approach that ensures comprehensive, organized medical records.

SOAP Sections Explained

S Subjective

The patient's description of their symptoms, concerns, and medical history. Includes:

  • Chief Complaint (CC)
  • History of Present Illness (HPI)
  • Review of Systems (ROS)
  • Past Medical/Surgical/Family/Social History

O Objective

Observable, measurable findings from the examination:

  • Vital Signs (BP, HR, Temp, RR, SpO2, Weight, Height)
  • Physical Examination findings
  • Lab results and imaging

A Assessment

The provider's clinical interpretation:

  • Diagnosis/Diagnoses (ICD-10 codes)
  • Differential diagnoses
  • Clinical impressions

P Plan

The treatment and follow-up strategy:

  • Medications prescribed
  • Orders (labs, imaging, referrals)
  • Patient education
  • Follow-up instructions

Creating a New Note

Open Patient Chart

Search for and select the patient from the Patients list.

Click "📝 New Note"

Opens a new SOAP note linked to this patient.

Select Note Type & Template

Choose the visit type (New Patient, Follow-up, Procedure, etc.) and apply a template if desired.

Document Each Section

Work through S, O, A, P sections. Use the 🎤 voice button for dictation.

Review and Sign

Review your note, then click "✍️ Sign Note" to finalize.

📄 Using Templates

Templates save time by pre-populating common text and structures for specific visit types.

Available Templates

  • Annual Physical — Comprehensive wellness exam
  • Follow-Up Visit — Brief follow-up structure
  • Sick Visit — Acute illness evaluation
  • Procedure Note — In-office procedures
  • Telehealth Visit — Virtual consultation

Applying a Template

When creating a new note, select a template from the dropdown menu. The note will be pre-filled with template content that you can customize.

Templates can include "smart phrases" — type shortcuts like ".hpi" that expand into full text blocks.

✍️ Signing Notes

Signing a note is a critical step that finalizes the documentation and locks it from further editing.

What Happens When You Sign

  • The note is marked as Signed
  • A timestamp and provider signature are added
  • The note becomes read-only — no direct edits allowed
  • The note is available for billing submission
  • Other providers can view the finalized documentation

Once signed, a note cannot be edited. If corrections are needed, you must add an Amendment (see below).

Note Statuses

Status Description Editable?
Draft Work in progress, not yet complete ✅ Yes
Pending Complete but awaiting signature ✅ Yes
Signed Finalized and locked ❌ No (Amendment only)

📎 Adding Amendments

Amendments allow you to add corrections or additional information to a signed note without altering the original documentation.

Open the Signed Note

Navigate to the encounter you need to amend.

Click "➕ Add Amendment"

Found at the bottom of the note or in the note actions menu.

Enter Amendment Text

Clearly describe the correction or additional information. Be specific about what is being changed or added.

Sign Amendment

The amendment is timestamped and signed, appearing below the original note.

Amendments preserve the integrity of the original note while allowing necessary corrections — this is a HIPAA-compliant approach to medical record modification.

📊 Patient Flow Board

The Flow Board provides a real-time view of patient status throughout their clinic visit, using a Kanban-style layout.

Flow Columns

Check-In

Patient has arrived and checked in

Roomed

Patient in exam room, waiting for provider

With Provider

Provider is with the patient

Check-Out

Visit complete, processing check-out

Check-In Workflow

Patient Arrives

Front desk marks patient as "Checked In" from the appointment card.

Verify Demographics & Insurance

Confirm patient information is current. Scan insurance cards if needed.

Move to "Roomed"

MA/Nurse takes patient to exam room, records vitals, and updates status.

Provider Sees Patient

Status updates to "With Provider" when the provider enters.

Check-Out

After visit, patient moves to Check-Out for scheduling follow-ups and payment.

Drag and drop patient cards between columns to quickly update their status. Wait times are calculated automatically and color-coded (green < 15min, yellow 15-30min, red > 30min).

💊 Prescriptions

The Prescriptions module allows providers to search for medications, write prescriptions, check for drug interactions, and manage patient medication lists.

Writing a Prescription

Open Patient Chart → Medications

Navigate to the patient and go to the Medications tab.

Click "➕ New Rx"

Opens the prescription writing interface.

Search for Medication

Type the drug name. Results include brand names, generics, and formulations.

Select Strength & Form

Choose the specific formulation (e.g., "Lisinopril 10mg tablet").

Enter Sig (Instructions)

Write directions: dose, frequency, route, duration. Example: "Take 1 tablet by mouth daily".

Set Quantity & Refills

Enter dispense quantity (e.g., #30) and number of refills (0-11).

Select Pharmacy

Choose from patient's preferred pharmacies or search for a new one.

Review & Send

Review the prescription, check interactions, then send electronically.

🔎 Drug Search

The drug database includes thousands of medications with:

  • Brand and generic names
  • Multiple formulations (tablet, capsule, liquid, injection, etc.)
  • Available strengths
  • DEA Schedule for controlled substances

Search Tips

  • Search by brand name: "Lipitor"
  • Search by generic: "atorvastatin"
  • Partial matches work: "lisino" finds Lisinopril
  • Filter by drug class in advanced search

⚠️ Drug Interactions

Amor Medical automatically checks for drug-drug interactions when prescribing.

Interaction Severity Levels

Level Description Action
Severe Life-threatening or permanent damage risk Avoid combination
Moderate May worsen condition or require monitoring Use with caution
Minor Minimal clinical significance Be aware

Always review interaction alerts before finalizing a prescription. You may override warnings with documentation of clinical reasoning.

Medication List Management

Maintain an accurate medication list by:

  • Reconciling — Update list each visit
  • Adding — Document new medications including OTC and supplements
  • Discontinuing — Mark medications no longer being taken
  • Documenting allergies — Record reactions in the allergy section

👨‍⚕️ Providers & Practices

Adding Providers

Navigate to Settings → Providers and click "➕ Add Provider":

  • Name — Full name with credentials (e.g., "Jane Smith, MD")
  • Credentials — MD, DO, NP, PA, RN, etc.
  • Specialty — Family Medicine, Internal Medicine, Cardiology, etc.

Practice Setup

Configure practice information in Settings → Practice:

  • Practice name and DBA
  • Tax ID / EIN
  • Practice NPI (Type 2)
  • Address and contact info
  • Hours of operation

Provider-Practice Relationships

Link providers to practice locations if you have multiple sites. This affects:

  • Which locations appear on prescriptions
  • Scheduling availability by location
  • Billing and claims routing

In the Settings modal:

  • App Version — Your current installed version

  • Click "🔍 Check for Updates" to manually check

Clearing Cache

If the app is behaving unexpectedly:

  • 🔄 Clear Cache & Reload — Clears cached files and reloads
  • 🗑️ Full Reset — Nuclear option that clears everything

Version Information

The version number follows semantic versioning (X.Y.Z):

  • X — Major version (significant changes)
  • Y — Minor version (new features)
  • Z — Patch version (bug fixes)

Last Updated shows when you last refreshed the app. If it's been a while, consider refreshing to get the latest improvements!
